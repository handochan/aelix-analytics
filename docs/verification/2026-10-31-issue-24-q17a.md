# Issue #24 — Q17-a를 출시 후보 0.32.0으로 다시 (2026-10-31)

[Issue #24](https://github.com/handochan/aelix-analytics/issues/24)의 출시 리허설(B6)에서 Q17-a(모델 없이 사람만의 분석)의 기능을 출시 후보로 다시 잰
기록이다. 방법과 판정 기준은 kit 0.25.0으로 잰 [#23 기록](2026-10-22-issue-23-q17.md)과 같다. 도구는 `26c28d0`의 `tools/human_e2e.py`(마지막 변경
`7388ecc`)다. #23의 리허설은 그 전 개정판(`965a46e` 작업 트리)으로 돌았고, 남은 프로세스를 고르는 규칙과 `not_covered`의 문구가 다르다.
수치·해시의 정본은 [JSON](2026-10-31-issue-24-q17a.json)이다.
측정 환경과 프로젝트는 이 기기에만 두고 커밋하지 않았다.

## 세션

에이전트가 #23의 리허설 스크립트(안내서 1–5단계)를 그대로 sandbox 세션으로 돌렸다. 마지막 세션은 Report v1을 다시 확인했다.
스크립트는 run 디렉터리(`.devstate`)에 있다.

**모델 호출 0.** `check --project <OUT>/work/q3-sales`가 prepare부터 판정 시점까지 막힌 시도를 다시 읽었고 0이었다.
- 프로젝트의 기록과 run 가운데 세션 시간 밖에 쓰인 것은 없다.
- aelix는 도구 환경에서도 프로젝트 환경에서도 import되지 않는다.
- 처음에는 `--project` 없이 돌렸다. 그 판정은 이 두 항목을 보지 않으므로(리뷰가 찾음), 프로젝트를 주고 다시 돌린 결과를 적었다.
- HOME의 `.aelix`에는 kit 신뢰 목록(`agent/analytics-projects.json`)뿐이다.
- 설치된 kit의 네트워크 사용은 `socket.gethostname`뿐이다.
- 막는 범위는 #23과 같다: 외부 IP와 Unix 소켓 연결, PATH의 모델 실행기, 그 설정·로그인·모델 저장소의 읽기.

**출력이 0.25.0과 같다.** 세션 1–5의 출력을 #23의 리허설 출력(`rehearsal-3`의 a1–a5)과 비교했다. run·Report·요청 ID, 시각, 경로, 시간 값을 가리면 같다.
- 일부러 틀린 첫 run은 `error`(ColumnNotFoundError)로 남고, 고친 run은 따로 `ok`다.
- 스크립트가 틀린 입력을 준 곳도 그때와 같고, 다음 세션이 바른 입력으로 다시 했다.
  - `--ref busan_daily.py::chart-1`(`scripts/`를 빠뜨림): 기록 e11은 저장됐고 그 참조는 버전에 묶이지 않았다(`none`). 다음 세션의 e18이
    `scripts/busan_daily.py::chart-1`로 버전에 묶였다(`inferred`).
  - `--based-on`에 run ID만 담은 JSON: kit이 `report_input_invalid`로 거절했다.
  - v1 저장이 거절된 채로 빈 이전 버전을 주고 v2를 저장하려 함: kit이 `name_not_portable`로 거절했다.
  - 출력을 줄이는 스크립트의 도우미가 응답에 없는 키를 찾아 traceback을 냈다(세션 2의 `KeyError: 'id'` 2건, 세션 3의 `KeyError: 'report'` 1건). 0.25.0의 출력에도 같다.
- 마지막 세션에서 v2 뒤의 v1이 그대로였다: `recording_status` complete, `content` resolved, 파일 2개, 근거 run 2개.
  - 파일: `monthly-revenue.png` 66,778 B, `요약.md` 318 B.

## 측정하지 않은 것

- 5단계의 Workspace 이동(결과 → 데이터·코드 → 발견·보고서). #23 때처럼 렌더만 했다. 사람의 탐색은 Q6이다.
- 사람의 사용성. 소유자 결정으로 갈음했다.
- 막지 못하는 경로는 #23 기록의 측정 범위와 같다. 분석 코드가 다른 곳의 모델 파일을 직접 여는 것, prepare 때 PATH에 없던 실행기가 그것이다.
- Q17-b(인계)는 모델이 필요하다. 후보로 다시 재는 것을 #24의 모델 캠페인(PR-3) 범위에 더했다(이 기록에서 정함).
