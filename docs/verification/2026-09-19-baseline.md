## Limits and remaining verification

Run success, input/code capture, same-environment replay and expected-value checks were
verified separately. The SDK chart preserved plotted data; the ordinary-library chart
retained an image and correctly warned that plotted data was not recorded. Old successful
and failed run bytes stayed unchanged through the tested operations. This does not establish
general immutability, complete lineage, retention of historical input bytes or reproduction
in another environment.

A separate self-review was performed. Independent review of these new changes, clean
release installation, real-model conversation, human-agent-human handoff, model-call
blocking/instrumentation, human usability, browser navigation and other operating systems
were not run. Q8/Q13/Q15/Q17 remain release gates with broader requirements. See
[the beta criteria](../BETA-QUALITY-GATES.md).
